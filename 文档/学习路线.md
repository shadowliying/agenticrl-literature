# 📚 Agentic RL 科研检索系统 - 学习路线

---

## 模块一：Multi-Agent 协作系统

| 小节 | 学习内容 | 关键面试点 |
|------|---------|-----------|
| **1.1 Agent 架构设计** | 7个Agent的职责划分、为什么这样设计 | "为什么要拆成7个而不是1个大Agent？" |
| **1.2 Agent 协作流程** | 10步执行链路、数据流向 | "描述一次完整的问答流程" |
| **1.3 MCP 协议** | 什么是MCP、为什么用它、消息格式 | "MCP和Function Calling有什么区别？" |
| **1.4 工具层实现** | 搜索引擎（Bing/SerpAPI）、URL解析、Docker沙箱 | "代码执行怎么保证安全？" |

---

## 模块二：检索增强（RAG）

| 小节 | 学习内容 | 关键面试点 |
|------|---------|-----------|
| **2.1 搜索策略** | 三种模式（单步单次/单步并发/多步多次）、关键词生成 | "怎么判断用哪种搜索策略？" |
| **2.2 BGE-Reranker** | Cross-Encoder原理、和Bi-Encoder的区别 | "为什么要重排序？直接用embedding不行吗？" |
| **2.3 充分性验证** | 怎么判断信息够不够、需不需要获取全文 | "摘要不够怎么办？" |

---

## 模块三：Memory 模块

| 小节 | 学习内容 | 关键面试点 |
|------|---------|-----------|
| **3.1 三层记忆架构** | 短期记忆、搜索缓存、实体记忆的设计原理 | "为什么要设计三层？各自解决什么问题？" |
| **3.2 短期记忆** | Redis存储对话历史、多轮追问处理 | "怎么处理'那京东呢'这种追问？" |
| **3.3 搜索缓存** | BGE语义匹配、0.85阈值设计、缓存命中逻辑 | "为什么不用精确匹配？语义匹配怎么做的？" |
| **3.4 实体记忆** | 实体提取、指代消解、话题主体追踪 | "怎么知道'它'指的是什么？" |
| **3.5 Memory与流程整合** | 何时读取、何时写入、对OrchestratorAgent决策的影响 | "Memory在哪些步骤被使用？" |

---

## 模块四：强化学习（核心重点）

| 小节 | 学习内容 | 关键面试点 |
|------|---------|-----------|
| **4.1 为什么用RL** | 规则方法的局限、序贯决策问题 | "为什么不直接让LLM自己决定？" |
| **4.2 MDP建模** | 什么是MDP、为什么适合这个问题 | "状态转移是确定的还是随机的？" |
| **4.3 状态设计** | 1024维向量的四部分、为什么这样设计 | "状态里为什么要放历史动作？" |
| **4.4 动作空间** | 5个动作、动作mask、高层vs低层 | "RL决定动作类型，LLM决定具体内容？" |
| **4.5 奖励函数** | 多目标加权、稀疏vs密集奖励 | "怎么平衡质量和效率？" |
| **4.6 GRPO算法** | 和PPO的区别、组内相对排名、无需Critic | "为什么不用PPO？GRPO的好处是什么？" |
| **4.7 训练流程** | 采样轨迹→计算advantage→梯度更新 | "一个batch怎么训练的？" |

---

## 模块五：数据与评估

| 小节 | 学习内容 | 关键面试点 |
|------|---------|-----------|
| **5.1 数据集构建** | 三个来源、标注格式、划分比例 | "训练数据哪来的？" |
| **5.2 评估指标** | 完成率、Top-5命中率、API成本、响应时间 | "怎么衡量系统好不好？" |
| **5.3 对比实验** | RL vs 规则基线、消融实验设计 | "怎么证明RL有用？" |

## 模块六：工程与部署（补充加分项）

| 小节 | 学习内容 | 关键面试点 |
|------|---------|-----------|
