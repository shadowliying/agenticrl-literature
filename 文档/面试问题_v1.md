根据岗位"**通用Agent算法 + 搜索创新**"，面试官会重点关注 **Agent 架构、搜索/RAG、强化学习**。

## 📌 项目一：车主问答系统（RAG方向）

### 🔍 RAG 架构相关

| 问题 | 回答要点 |
|------|----------|
| **为什么用双路召回（向量+BM25）？** | 向量捕捉语义，BM25捕捉关键词；互补，覆盖率更高 |
| **双路融合怎么做的？分数怎么归一化？** | RRF (Reciprocal Rank Fusion) 或加权融合；min-max归一化 |
| **为什么用 M3E 不用 BGE？** | M3E 中文效果好、轻量；BGE-large 更强但推理慢 |
| **Reranker 和召回阶段的 Embedding 有什么区别？** | 召回是双塔独立编码，Reranker 是 cross-encoder 交互编码，精度更高但慢 |

### 🎯 微调相关

| 问题 | 回答要点 |
|------|----------|
| **Hard Negative Mining 具体怎么做的？** | 用当前模型召回 top-k，取排名靠前但不是正例的作为难负例 |
| **为什么 Hard Negative 有效？** | 普通负例太简单，模型学不到细粒度区分 |
| **对比学习的损失函数是什么？** | InfoNCE / Triplet Loss，拉近正例推远负例 |
| **4200条数据够吗？怎么判断数据量是否足够？** | 看验证集指标是否收敛；做了数据量消融实验 |

### ⚡ 部署相关

| 问题 | 回答要点 |
|------|----------|
| **vLLM 为什么快？** | PagedAttention 管理 KV Cache，减少显存碎片；连续批处理 |
| **512并发怎么测的？压测工具？** | locust / wrk；固定 QPS 看延迟分布 |
| **首Token延迟和吞吐量的trade-off？** | 批大了吞吐高但延迟也高；C端场景优先保延迟 |

## 📌 项目二：科研Agent系统（Agent + RL方向）

### 🤖 Agent 架构相关（**重点！**）

| 问题 | 回答要点 |
|------|----------|
| **7个Agent分别是什么？为什么这样设计？** | Orchestrator/Optimizer/Selector/Validator/Reorchestrator/Code/Assistant；单一职责、可复用 |
| **Agent之间怎么通信的？** | 标准化消息格式；Orchestrator 中心调度 |
| **MCP协议是什么？为什么用它？** | Model Context Protocol，标准化工具调用接口；解耦Agent和工具 |
| **怎么处理Agent调用失败/超时？** | 重试机制、fallback策略、超时熔断 |
| **和 LangChain/AutoGPT 的区别？** | 我们用RL优化决策，不是纯prompt驱动 |

### 🎮 强化学习相关（**核心！**）

| 问题 | 回答要点 |
|------|----------|
| **为什么用强化学习？规则不行吗？** | 规则无法自适应、无法从错误学习；RL可以探索更优策略 |
| **为什么选GRPO不选PPO？** | 不需要Critic网络，显存省一半；组内对比自带baseline |
| **GRPO的Group是什么意思？** | 每个prompt生成4个候选，组内对比计算advantage |
| **奖励函数怎么设计的？** | 三维度：Quality(1.0) + Efficiency(0.3) + InfoGain(0.2) |
| **Quality怎么评估？没有ground truth怎么办？** | 规则70%（引用、长度、覆盖）+ LLM-as-Judge 30% |
| **KL散度的作用？β怎么选的？** | 防止模型偏离太远；β=0.1，实验调的 |
| **训练数据是什么格式？** | 只需要prompt，轨迹是模型rollout时生成的 |
| **LoRA的参数怎么选的？** | r=16, alpha=32；实验对比r=8/16/32 |

### 🔄 MDP建模相关

| 问题 | 回答要点 |
|------|----------|
| **状态空间怎么定义的？** | Query + 历史动作 + 检索结果摘要，编码为文本 |
| **5个动作是怎么确定的？** | 分析科研场景的核心操作；SEARCH/REFINE/READ_FULL/ANSWER/CODE |
| **折扣因子γ是多少？为什么？** | γ=0.99，因为最终答案质量最重要，要考虑长期奖励 |
| **Episode什么时候结束？** | 选择ANSWER动作 或 超过最大步数(10步) |
