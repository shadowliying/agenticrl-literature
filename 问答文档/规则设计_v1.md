# 规则设计（v1）

> 本文档用于说明 v1 系统中 **Plan 规则、Validate 规则、State 判断逻辑**。
> 原则：规则简单、可执行、无需 LLM 解释。

---

## 1. Plan 规则设计（简化版）

**核心思想**：Plan 里写“机器能直接执行的规则”，避免纯自然语言。

**推荐字段**（写在 `PlanStep.metadata` 或 `success_rules/rollback_rules`）：
- `required_slots`：必须覆盖的关键槽位（如 time/number/comparison）
- `min_snippets`：最少证据数
- `sufficiency_threshold`：充分性阈值
- `replan_threshold`：重规划阈值

**示例（Plan 片段）**
```json
{
  "step_id": "S2",
  "action": "VALIDATE",
  "success_rules": [
    {"type": "sufficiency_score_ge", "value": 0.75}
  ],
  "rollback_rules": [
    {"type": "sufficiency_score_lt", "value": 0.60}
  ],
  "metadata": {
    "required_slots": ["time", "number", "comparison"],
    "min_snippets": 2,
    "sufficiency_threshold": 0.75,
    "replan_threshold": 0.60
  }
}
```

> **中文注释**：Plan 负责“规定标准”，不负责判断结果。

## 2. Validate 规则设计（规则优先）

**输入**：
- `evidence_snippets`（检索证据）
- `plan_rules`（来自 Plan 的规则）
- `context`（可选：previous_snippets、conflicts 等）

**规则来源**：
1. **Plan 规则**（必须执行）
2. **Validate 内置规则**（通用安全规则）

### 2.1 分数计算规则（确定版）

**(1) coverage 覆盖度**
- 计算方式：`1 - missing_slots / total_slots`

**(2) relevance 相关性**
- 证据中命中问题关键词的比例

**(3) support_strength 支持强度**
- 证据平均长度 + 是否含数字
- `base = min(1, avg_len/200)`
- 若包含数字：`base += 0.2`（上限 1.0）

**(4) info_gain 信息增益**
- 新证据数 / 当前证据总数

**(5) consistency 一致性**
- `consistency = 1 - conflict_ratio`

**(6) source_quality 来源质量**
- 有评分取平均
- 无评分默认 0.5

**(7) freshness 时效性**
- 有评分取平均
- 无评分默认 0.5

### 2.2 综合评分公式（固定）
```
sufficiency_score =
  0.35 * coverage
+ 0.20 * relevance
+ 0.15 * support_strength
+ 0.10 * consistency
+ 0.10 * source_quality
+ 0.05 * freshness
+ 0.05 * info_gain
```

### 2.3 硬性门槛（触发则直接不足）
- 关键槽位缺失（missing_slots 非空）
- 冲突比例 > 0.4
- 证据数量 < min_snippets
- 高风险问题且来源质量 < 0.4
- 时间敏感问题且时效性 < 0.4

**输出**（结构化）
```json
{
  "sufficiency": true,
  "sufficiency_score": 0.82,
  "missing_slots": [],
  "conflicts": [],
  "suggested_action": "synthesize"
}
```

> **中文注释**：Validate 是“裁判”，只输出结构化结果，不决定下一步。

## 3. State 判断逻辑（最小规则集）

**输入**：
- `sufficiency_score`
- `sufficiency_threshold`
- `replan_threshold`
- `conflict_ratio`（可选）

**判断规则（固定）**：
- `score >= sufficiency_threshold` → **SYNTHESIS**
- `score < replan_threshold` → **REPLAN**
- 其他 → **RETRIEVE**

> **中文注释**：StateMachine 只负责“下一步去哪”，不理解证据内容。

---

## 4. 简单流程例子

**问题**：2023 年中国新能源汽车销量是多少？同比增长多少？

**Plan 规则**：
- `required_slots = [time, number, comparison]`
- `min_snippets = 2`
- `sufficiency_threshold = 0.75`
- `replan_threshold = 0.60`

**Validate 结果**：
- `sufficiency_score = 0.82`
- `missing_slots = []`

**State 判断**：
- `0.82 >= 0.75` → 进入 **SYNTHESIS**

---

> 结论：Plan 定标准，Validate 验标准，State 决定下一步。
